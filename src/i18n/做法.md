# 官网多语言做法（2026-11-09 起）

七种语言：en（默认，网址不带前缀）、zh-Hans（/zh-hans）、zh-Hant（/zh-hant）、ja、ko、vi、th。
工具：next-intl 4.14.9（固定版本）。配置在 `src/i18n/`，文字在 `src/messages/<语言>/<名字>.json`。

## 文字文件
- 每个区一份：`common`、`nav`、`footer`、`home`、`services`、`pricing`、`contact`、`coverage`、`sitemapPage`、`notFound`、`meta`、`serviceNames`、`booking`、`orders`、`review`、`track`、`welcome`、`referral`、`terms`、`privacy`。新加一份要登记到 `src/i18n/namespaces.js`。
- 英文是底稿。别的语言漏了哪句，页面自动用英文顶上（`src/i18n/request.js`）。
- 键名用小驼峰、按区分层：`{"step1": {"title": "…"}}`，代码里写 `t('step1.title')`。
- 变量用 `{name}`；数量用 `{count, plural, one {# minute} other {# minutes}}`；句子里要加粗或链接用 `<b>…</b>`、`<link>…</link>`，代码里 `t.rich('key', { b: (c) => <b>{c}</b> })`。
- 文字里不许出现裸的 `{` `}`。英文撇号尽量用 ’（弯的）。
- 品牌名 EasyGoSpa、技师名字、电话、邮箱、价格数字不进文字文件，用变量塞进去。

## 代码里怎么用
- 浏览器里跑的组件（'use client'）：`import { useTranslations, useLocale } from 'next-intl'`，`const t = useTranslations('booking')`。
- 服务器上的页面：`import { getTranslations, setRequestLocale } from 'next-intl/server'`，`const t = await getTranslations({ locale, namespace: 'terms' })`。每个页面开头 `const { locale } = await params; setRequestLocale(locale);`。
- 站内链接：`import { Link, useRouter, usePathname } from '@/i18n/navigation'`（会自动带上当前语言）。不要再用 next/link 和 next/navigation 的 useRouter/usePathname 做站内跳转。
- 日期时间：`intlLocale(locale)`（`@/i18n/routing`）给出地区写法，时区一律 `Asia/Manila`。英文的显示结果要跟以前一字不差。
- 发给服务器的东西（项目名、状态代码、备注、给公司 WhatsApp 的预填话）不翻译，保持英文。脸书像素事件名不动。
- 服务器接口回来的英文报错：能按代码对应的就翻；只有一句英文的原样显示。
